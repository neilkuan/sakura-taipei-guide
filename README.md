# 台北さんぽ 🌸

給さくら與家人的日文台北旅遊指南，包含 3、4、5 天行程、九份、中山、信義、大稻埕與北投，以及櫻花歡迎動畫。

網站：https://tw.neilkuan.click

## 維護

純 HTML、CSS、JavaScript，無需安裝套件或建置。修改根目錄的 `index.html`、`style.css`、`app.js` 與 `taipei.svg`，推送至 `main` 後由 GitHub Pages 自動發布。

本機預覽：`python3 -m http.server 4173`。

`CNAME` 設定自訂網域。DNS 的 `tw` CNAME 應直接指向 `neilkuan.github.io`。
